# Полная встроенная база

Все перечисленные файлы включены в пакет. Для выполнения навыка Google Drive не нужен. Оригиналы сохранены как полные текстовые выгрузки девяти документов, без сокращения; это полнота полученного текста, а не копия визуального оформления Google Docs.

## Обязательный общий маршрут

При первой содержательной задаче прочитай:
1. [Полную авторскую методику ПРОФИ](originals/profi-full.txt).
2. [Мастер-гайд по промтингу 2.0](originals/master-guide.txt).
3. Редакционные справочники profi-workflow.md, techniques.md и business-examples.md.

Для задачи с конкретной техникой дополнительно прочитай соответствующий раздел подробного разбора или практикума. Не перечитывай уже изученные документы в том же диалоге, пока задача не изменилась существенно.

## Что оригиналы не доказывают

В материалах есть проценты улучшения без источников, старые рейтинги моделей, эмоциональные усилители и команды, якобы переключающие настройки. Они сохранены для полноты архива, но не переносятся как достоверные рекомендации в готовые промты. Нет гарантии качества от роли, названия техники или самопроверки. Нужны реальные критерии и проверка на задаче.

При конфликте применяй редакционные правила SKILL.md: профессиональная роль без выдуманных регалий, ясная цель, реальные данные, проверяемый формат и проверка результата; без требования скрытых рассуждений.
