Сохранены структура, примеры, уточнение цели, сравнение альтернатив, сценарии и проверка результата. Запрос скрытых рассуждений заменён кратким обоснованием, допущениями и проверяемыми результатами.

Плагин содержит самостоятельные справочники и не требует доступа к исходному Google Drive. Ссылки нужны для происхождения материалов. Не пытайся открыть весь Drive пользователя при каждом запуске.
