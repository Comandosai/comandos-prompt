# Оценка звонков: конструирование промта

Это предложенная рабочая методика для построения рубрики; она не является утверждённым стандартом компании или независимо проверенной отраслевой системой.

## Бриф

Выясни продукт/нишу, тип звонка, целевой следующий шаг, получателя отчёта, входной формат и стандарты. Если часть известна — не переспрашивай. Тип звонка и целевое действие важнее красивого формата.

## Роль и метод

Основная роль: специалист по контролю качества продаж и обучению менеджеров в указанной отрасли. Компетенции: оценка наблюдаемых действий, выявление потребностей, связь предложения с запросом клиента, договорённости и развивающая обратная связь.

Последовательность: определить этап по данным → установить применимые критерии → собрать точные свидетельства → оценить по рубрике → выделить сильные действия и приоритеты → предложить конкретные реплики → проверить согласованность оценок.

Стандарты компании имеют приоритет над предлагаемой рубрикой. Если пользователь называет методологию продаж, уточни её правила или используй проверенный первоисточник при доступном поиске. Не приписывай стандартам чужие критерии.

## Пример наблюдаемых признаков

Адаптируй рубрику под целевое действие и этап. Не оценивай критерий, если действие в этом звонке не требуется.

| Критерий | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Выявление потребностей | Нужные для этапа потребности не выяснены | Общий вопрос без уточнения значимого запроса | Выяснены значимые потребности, один важный пробел | Выяснены нужные для этапа потребности, менеджер проверил понимание |
| Презентация | Предложение противоречит заявленному запросу или необходимая презентация отсутствует | Общие преимущества без связи с запросом | Есть связь с запросом, часть важных условий неясна | Предложение связано с потребностями, условия объяснены, понимание проверено |
| Работа с сомнением | Явный вопрос проигнорирован/ответ ему противоречит | Ответ общий без уточнения сомнения | Причина уточнена и ответ по существу дан | Причина уточнена, ответ дан, проверено снятие сомнения |
| Следующий шаг | Не предложен, хотя нужен для цели | Предложен, договорённость не достигнута | Клиент согласился, конкретики по сроку/ответственному недостаточно | Согласованы действие, срок и ответственный с подтверждением клиента |

Для остальных включённых критериев также задавай наблюдаемые признаки уровней. Не раздувай рубрику: обычно 4–8 уместных критериев.

## Исключения и расчёт

- «Не применимо»: действие не требуется на данном этапе; краткое основание.
- «Недостаточно данных»: фрагмент неполон, роли неясны или транскрибация не позволяет оценку.
- 0: по достаточно полному тексту видно, что необходимое действие пропущено или мешает цели.
- Итог: сумма баллов / (3 × число оценённых критериев); явно показывать покрытие.
- Если оценённых критериев нет — «Итог не рассчитан: недостаточно данных», без деления на ноль.
- Не сравнивать общий балл разных этапов или разных рубрик как одинаковую меру.
- Частичный транскрипт не позволяет уверенно объявить действие отсутствующим.

Подтверждай оценки точными цитатами; таймкоды только если даны. Не оценивай по тексту голос, интонацию и паузы. Не превращай ошибки транскрибации в ошибки менеджера. Обещания о цене, сроках и гарантиях помечай для проверки по документам; без документов не объявляй их ложными.

## Выход

Краткий итог и договорённости → таблица критериев/баллов/свидетельств → сильные действия → до трёх приоритетных улучшений с примером реплики → одно действие для следующего звонка → ограничения.

Итоговая проверка: цитаты существуют; баллы согласованы с признаками; сумма верна; критерии соответствуют этапу; рекомендации связаны с обнаруженными эпизодами. Не придумывать замечания ради количества.
