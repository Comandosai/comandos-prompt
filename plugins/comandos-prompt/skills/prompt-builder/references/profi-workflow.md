# ПРОФИ: методологический цикл

Редакционная адаптация авторской методики Дмитрия Попова. ПРОФИ — каркас; дополнительные техники выбираются по задаче.

| Элемент | Что установить | Что включить в промт |
|---|---|---|
| П — проблема и цель | Какое решение/действие поможет человеку; как выглядит полезный результат | Конкретную задачу и цель использования |
| Р — роль и контекст | Какая компетенция нужна; отрасль, процесс, аудитория и этап | Явную специализацию, компетенции и контекст |
| О — ограничения и критерии | Формат, объём, ресурсы, допустимые действия, признаки качества | Проверяемые требования и правила выбора при конфликте |
| Ф — факты и примеры | Доступные данные, источники, стандарты и образцы | Входные данные, границы фактов, правила отсутствующих данных |
| И — итерации и проверка | Как обнаружить ошибку и улучшить результат | Конкретные проверки и возможность правки по обратной связи |

Не превращай каркас в анкету: сначала извлеки известное. Уточни только то, что меняет решение. Роль конструирует ассистент, пользователь описывает задачу.

## Глубина

Простая задача: ясная роль + задача + контекст + формат + короткая проверка.
Сложная/повторяемая задача: дополнительно этапы работы, конкретная рубрика, обработка исключений, опора на источники и проверка результата.
Если несколько этапов требуют новых данных или согласования, раздели работу на последовательные промты.

## Выбор усиления

Нужен стабильный образец — Few-Shot. Нужны зависимые действия — декомпозиция. Нужно решение между вариантами — сравнительный анализ. Неопределённость — сценарии. Уже есть результат — итеративная правка по критериям.

Проверка должна быть предметной: для отчёта — правильность единиц и расчётов; для письма — соответствие цели и отсутствие неподтверждённых обещаний; для звонка — соответствие этапу, цитаты и устойчивость шкалы.

## Регрессия из первого теста

На ответ «малоэтажное строительство; оценка по критериям; транскрибация» не выдавай окончательный универсальный промт. Критически неизвестны тип звонка, целевое действие и стандарты. Спроси коротко: «Это первый контакт по заявке, холодный или повторный звонок? Какой следующий шаг нужен? Есть ли ваши критерии или предложить рабочую систему?»

После ответа используй профильную роль и методику оценки звонков. При просьбе без уточнений создай обозначенный черновик, адаптируемый к этапу.
