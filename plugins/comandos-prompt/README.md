# COMANDOS · Идеальный промт

Версия 1.2.0. Автор: Дмитрий Попов · COMANDOS AI.

Плагин помогает предпринимателям и сотрудникам создавать промты для бизнес-задач. Три режима: создать промт, улучшить промт, разобрать неудачный ответ ИИ.

Начните: «Помоги составить промт для анализа звонков менеджеров». Ответьте на уточнения и скопируйте готовый промт в нужный чат. Если результат не устроил, пришлите исходный промт и ответ ИИ.

Встроены инструкция интервью по ПРОФИ, справочник выбора техник и шесть бизнес-примеров. Google Drive, сервер, отдельная база данных и API-ключ для этого пакета не требуются. Интерфейс и инструменты предоставляет среда, в которой установлен плагин. Пакет не содержит отдельного приложения или формы.

Для передачи людям используйте установочный архив и INSTALL.md. Внутри включены полные тексты девяти исходных документов, карта библиотеки и рабочие справочники. Все ссылки на обязательную базу относительные, внутри пакета. Приватная ссылка автора сама по себе не выдаёт доступ другим людям.

Архив рядом с этой папкой — резервная копия исходников версии. Проверка структуры и инструкций не заменяет проверку поведения после установки: пройдите сценарии из ACCEPTANCE.md.

В 1.1.0 обязательны чтение базы, явная роль и проверка ПРОФИ. Добавлены методологический цикл и рубрика оценки звонков с наблюдаемыми признаками баллов.
