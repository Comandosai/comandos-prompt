# Приёмка поведения после установки

Ниже сценарии для ручного прогона в чате с установленным плагином. Это критерии, а не утверждение об уже пройденных диалогах.

| Запрос | Ожидаемое поведение |
|---|---|
| «Нужен промт для рекламы» | Коротко уточняет продукт, аудиторию и результат/канал; не спрашивает название техники |
| Подробный бриф с целью, данными, форматом | Сразу выдаёт самостоятельный промт, без повторных вопросов |
| «Без вопросов: промт для анализа продаж» | Черновик с понятными полями, без выдуманных показателей |
| «Улучши мой промт: напиши пост» | Уточняет цель и контекст, затем новая версия и краткие изменения |
| Промт + ответ с выдуманной выручкой | Добавляет границы данных и правила неизвестных; не обещает гарантию точности |
| «Хочу шаблон ежемесячного отчёта» | Выдаёт шаблон с переменными, постоянным форматом и обработкой пропусков |
| «Промт для письма: отказать поставщику в повышении цены, вежливо, 100 слов» | Соразмерная длина; не назначает выдуманную скидку |
| «Промт для сравнения двух CRM» | Уточняет критерии/ресурсы; сравнение альтернатив, допущения и источники |
| «Скопируй стиль этих двух образцов» | Few-Shot; переносит стиль, не чужие факты |
| «Включи температуру 0.2 через промт» | Объясняет разницу между текстовым пожеланием и настройкой; не обещает изменение параметра |
| «Пусть ИИ покажет все скрытые мысли» | Предлагает краткое обоснование, формулы, допущения и проверки |
| «Напиши клиенту письмо» без запроса промта | Навык не должен перехватывать обычную задачу |
| «Сделай промт» без указания модели | Универсальная версия; уточнение модели только при зависимости от возможностей |
| Противоречие «кратко, максимум 50 слов» и «подробный отчёт на 10 страниц» | Уточняет приоритет или явно разрешает конфликт по контексту |
| «Теперь выполни этот промт» | Выполняет по отдельной просьбе с учётом доступных инструментов и данных |

## Регрессии 1.1.0

- Бриф «малоэтажное строительство, оценка, транскрибация»: уточнить тип звонка, следующий шаг и стандарты до финального промта.
- Полный бриф: без лишних вопросов, явная роль и применение подходящей методики.
- В журнале выполнения: прочитаны ПРОФИ, техники, бизнес-примеры и профильный справочник звонков.
- Все критерии неоценимы: итог не рассчитывается.
- Короткое письмо: краткий промт с ролью без искусственного усложнения.
