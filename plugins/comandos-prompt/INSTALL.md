# Установка COMANDOS · Идеальный промт 1.2.0

## Что передавать

Для установки без доступа к аккаунту автора передайте архив COMANDOS-Prompt-1.2.0-install.zip. В нём плагин и локальный каталог для обнаружения. Не нужно подключать Google Drive автора, Obsidian или сервер. Нужен собственный аккаунт пользователя и клиент с поддержкой плагинов/локальных каталогов.

Это не обещание поддержки любого аккаунта ChatGPT: доступность плагинов зависит от клиента и настроек аккаунта. Приватная ссылка автора сама по себе не даёт доступ внешним людям.

## Через Codex CLI и локальный каталог

1. Установите Codex и войдите в собственный аккаунт. Если команда codex уже доступна, повторная установка не нужна.
2. Распакуйте архив полностью. Не переносите только SKILL.md: папка references и оригиналы нужны для работы.
3. Откройте терминал в распакованной папке comandos-prompt-distribution.
4. Выполните:

~~~sh
codex plugin marketplace add .
codex plugin add comandos-prompt@comandos-prompt-local
~~~

5. Проверьте наличие плагина:

~~~sh
codex plugin list
~~~

6. Перезапустите приложение Codex/ChatGPT desktop, если используете графический клиент. В Plugins выберите локальный источник COMANDOS Prompt и установите/включите плагин, если клиент ещё требует этого действия.
7. Создайте новый чат, выберите COMANDOS · Идеальный промт и напишите: «Помоги составить промт для моей бизнес-задачи».

Папку после регистрации каталога не удаляйте: каталог ссылается на её содержимое. Для обновления распакуйте новый пакет в постоянное место и обновите локальный источник. Не устанавливайте неизвестные изменённые копии.

## Через каталог проекта, без ручного редактирования конфигурации

Распакованная папка уже содержит .agents/plugins/marketplace.json и .codex/config.toml. Откройте именно эту папку как проект в поддерживаемом локальном клиенте. При необходимости подтвердите доверие папке, затем перезапустите клиент и найдите COMANDOS Prompt в источниках Plugins. Если локальный источник не отображается, используйте команды выше.

## Через ChatGPT web

Локальный каталог не является веб-установкой. Для браузера нужно, чтобы плагин был доступен аккаунту получателя через поддерживаемое предоставление доступа/каталог, или чтобы получатель имел возможность загрузить пакет через Plugin Creator. Эти возможности не включаются ZIP-архивом.

Если Plugin Creator доступен, прикрепите отдельный comandos-prompt-1.2.0.zip и попросите: «Создай приватный плагин из приложенного пакета, сохрани все инструкции и reference-файлы». После создания установите его и начните новый чат. Загрузка через интерфейс чужого аккаунта в этой проверке не выполнялась.

Если участникам нужен единый браузерный адрес без установки через CLI, владельцу требуется поддерживаемое распространение плагина вне личного аккаунта. Публикация в рабочей области ограничена этой рабочей областью; публичный каталог требует отдельного процесса публикации.

## Проверка после установки

Отправьте: «Мы продаём малоэтажное строительство. Нужен промт для оценки транскриптов звонков».

Ожидается уточнение типа звонка, целевого следующего шага и стандартов, если эти сведения не указаны. После ответов — готовый промт с профессиональной ролью, методикой, конкретными критериями и правилами недостаточных данных.

Файлы методологии должны читаться внутри установленного comandos-prompt/skills/prompt-builder/references. Чтение AGENTS.md вашего компьютера может отдельно происходить по глобальным правилам клиента; это не зависимость предметной базы плагина.

## Источник инструкции

Официальная документация: https://developers.openai.com/plugins/build/plugins — локальные каталоги, относительные пути и команды регистрации. Синтаксис plugin add дополнительно проверен в установленном Codex CLI через help.
