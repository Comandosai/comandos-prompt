# COMANDOS · Идеальный промт

Бесплатный конструктор бизнес-промтов по методике ПРОФИ Дмитрия Попова. Уточняет задачу, выбирает подход и готовит промт с ролью, исходными данными, форматом и критериями качества. Внутри — полные тексты девяти методических документов и рабочие примеры. Компьютер и Google Drive автора не нужны.

## Забрать в свой ChatGPT

**[Скачать плагин 1.2.0](https://github.com/Comandosai/comandos-prompt/releases/download/v1.2.0/comandos-prompt-1.2.0.zip)**

1. Откройте новый чат в своём ChatGPT и выберите **@Plugin Creator**, если он доступен вашему аккаунту.
2. Прикрепите скачанный ZIP и отправьте:

> Создай в моём аккаунте приватный плагин из прикреплённого ZIP. Сохрани все инструкции, девять исходных документов, примеры и относительные пути без сокращений. Если инструмент сохранения недоступен, прямо сообщи об этом. После создания дай ссылку на мой плагин и инструкцию установки.

3. Откройте собственную страницу созданного плагина и установите его.
4. Начните новый чат, выберите COMANDOS через `@` и напишите: «Помоги составить промт для моей бизнес-задачи».

Скачивание ZIP само по себе не устанавливает плагин. Нужны доступный Plugin Creator и разрешение использовать плагины. Импорт в чужом обычном веб-аккаунте ещё не проверен; наличие Creator зависит от аккаунта и настроек. Пакет успешно сохранён в аккаунт автора и прошёл локальные функциональные проверки.

## Если Plugin Creator отсутствует

[Скачайте пакет для личного Project](https://github.com/Comandosai/comandos-prompt/releases/download/v1.2.0/COMANDOS-Prompt-Project.zip). Создайте свой проект в ChatGPT, вставьте `PROJECT-INSTRUCTIONS.txt` в настройки проекта и загрузите четыре файла `01`–`04`. Начните чат внутри проекта. Все девять оригинальных документов сохранены в этих файлах целиком. Это режим проекта; поведение адаптации на аккаунте получателя ещё требует проверки.

Если ваш интерфейс поддерживает загрузку Skills, в релизе есть отдельный `comandos-prompt-skill-1.2.0.zip`. Его импорт в веб-интерфейсе не проверен нами.

## Установка из GitHub в Codex

```sh
codex plugin marketplace add Comandosai/comandos-prompt
codex plugin add comandos-prompt@comandos-prompt-local
```

Начните новую сессию. Эти команды предназначены для Codex CLI и не являются командами установки в обычном чате ChatGPT.

## Проверить работу

«Мы продаём строительство частных домов. Нужен промт для оценки звонков». Ожидаются уточнения о типе звонка, следующем шаге и стандартах; после ответов — готовый промт с профессиональной ролью и конкретными критериями.
