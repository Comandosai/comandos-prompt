ЛИЧНАЯ КОПИЯ ПЛАГИНА В CHATGPT

1. Скачайте comandos-prompt-1.2.0.zip. Это архив одного плагина, не marketplace install ZIP.
2. В своём ChatGPT откройте новый чат и через @ выберите Plugin Creator, если он доступен вашему аккаунту.
3. Прикрепите ZIP и отправьте:

Создай в моём аккаунте приватный плагин из прикреплённого ZIP. Используй пакет целиком: сохрани skills/prompt-builder/SKILL.md, все reference-файлы, девять исходных документов, примеры и относительные пути без сокращения и переписывания. Это инструкция для создания моего плагина, а не просьба просто применить промт в текущем чате. Если у тебя нет инструмента сохранения плагина, прямо сообщи об этом. После сохранения дай ссылку на мой плагин и инструкцию установки. Подтверди количество исходных документов.

4. Откройте полученную собственную страницу плагина, установите, начните НОВЫЙ чат и выберите COMANDOS через @.
5. Тест: «Мы продаём строительство частных домов. Нужен промт для оценки звонков». Ассистент должен уточнить тип звонка, следующий шаг и стандарты. После ответов — выдать промт с ролью и конкретными критериями.

Этот путь требует доступного Plugin Creator и разрешения использовать плагины. Создание приватного плагина подтверждено действующим инструментом; импорт в чужом обычном веб-аккаунте ещё не испытан. GitHub только предоставляет ZIP для скачивания, а не автоматическую установку.

Если Plugin Creator недоступен, используйте COMANDOS-Prompt-Project.zip: личный Project, инструкция и четыре полных TXT-файла. Если есть нативная кнопка загрузки Skills, для неё приготовлен отдельный comandos-prompt-skill-1.2.0.zip; не загружайте туда plugin marketplace archive. Прямой импорт этого skill ZIP в вашем интерфейсе ещё требует проверки.
